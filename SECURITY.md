# Security Policy

## Supported versions

gobento is pre-1.0. Only the latest minor release receives security fixes.

| Version | Supported |
|---|---|
| Latest minor release (currently `0.1.x`) | Yes |
| Older releases | No |

The latest release is listed on the
[releases page](https://github.com/Tales-of-zuna/gobento/releases).

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.**

Report them privately through GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/Tales-of-zuna/gobento/security)
   of the repository and click **Report a vulnerability**, or go directly to
   <https://github.com/Tales-of-zuna/gobento/security/advisories/new>.
2. Describe the issue, including:
   - the affected gobento version or commit,
   - steps to reproduce, or a proof of concept,
   - the impact you expect (for example, what an attacker could do).

Only you and the maintainers can see the report. See GitHub's guide on
[privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
for details.

## What to expect

- **Acknowledgement within 7 days** of your report.
- An initial assessment, including whether we consider it a vulnerability,
  as soon as we have reproduced it.
- Regular updates while we work on a fix.

## Disclosure process

1. We confirm the problem and determine the affected versions.
2. We prepare a fix in a private security advisory, and may invite you to
   collaborate on it.
3. We release the fix and publish the advisory, requesting a CVE where
   appropriate.
4. We credit you in the advisory, unless you prefer to remain anonymous.

Please give us a reasonable amount of time to release a fix before disclosing
the issue publicly. We aim to publish fixes within 90 days of the report, and
we will coordinate the disclosure date with you.
