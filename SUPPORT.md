# Getting help

## Where to ask

gobento does not have GitHub Discussions yet. Until it does, ask questions by
[opening an issue](https://github.com/Tales-of-zuna/gobento/issues/new/choose)
and adding the `question` label. Please search
[existing issues](https://github.com/Tales-of-zuna/gobento/issues?q=is%3Aissue)
first; your question may already have an answer.

## What to include

A good question gets a faster answer. Please include:

- what you are trying to do, and what you have tried so far,
- your gobento version, operating system, and Go version (`go version`),
- the exact command you ran and its full output, if any.

## What not to file as an issue

- **Security vulnerabilities.** Report them privately as described in
  [SECURITY.md](SECURITY.md).
- **Problems in generated code that come from an upstream library**, such as a
  bug in a framework or database driver. Report those to the upstream project.
  If gobento generates the wrong code or the wrong versions, that is a gobento
  issue.
- **General Go questions** that are not about gobento. Resources such as the
  [Go documentation](https://go.dev/doc/) and the
  [Go community](https://go.dev/wiki/#the-go-community) are a better place.

For bugs and feature ideas, use the bug report, feature request, or component
request forms when you open an issue. To contribute a change, see
[CONTRIBUTING.md](CONTRIBUTING.md).
